## Conventions

- One file per step in `steps/`. When a step finishes, mark it done in `02-roadmap.md` and
  add a short "Outcome" section to its step file (what was built, what changed from the plan).
- Any change of direction goes in `01-decisions.md` with the date and the reason.
- Keep step files short: what, why, where, done-when. Don't repeat the assignment text;
  link to `context/` instead.
